# ShopEase — E-commerce Frontend

A responsive React shopping UI built with Vite, React Router and Redux Toolkit. This Week 05 minor-project starter demonstrates reusable components, global cart/wishlist state, product filtering and routing.

## Features
- Home page and featured products
- Product catalog with search, category filter and price sorting
- Product details pages
- Redux Toolkit cart (add/remove/change quantity, totals)
- Wishlist with persisted state
- LocalStorage cart and wishlist persistence
- Responsive layout
- Checkout demo placeholder (no payment processing)

## Setup
```bash
npm install
npm run dev
```
Open the URL printed by Vite (typically http://localhost:5173).

## Build
```bash
npm run build
```

## Structure
`src/components`, `src/pages`, `src/store`, `src/services`

Product images use external Unsplash image URLs and require internet access.
